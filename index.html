Multi-Agent Mortgage Underwriting System Agentic AI

For my Johns Hopkins Agentic AI capstone, I implemented a LangGraph workflow that analyzes mortgage applications using specialist agents for credit, income, assets, and collateral. A critic agent and a decision agent combine their findings into a recommendation. The system uses RAG for policy retrieval and deterministic tools for DTI, LTV, and credit-tier calculations. Before analysis, it masks the SSN, phone number, and address, and it routes high-risk or flagged cases to human review.

Evaluation: I ran the workflow on three synthetic applicants: strong, borderline, and weak. Its decisions matched the expected approved, conditional, and declined outcomes.

“You demonstrated a high level of technical proficiency by building a functional multi-agent mortgage underwriting system using LangGraph… Your work provides a robust foundation for automated underwriting and demonstrates a clear grasp of agentic orchestration.”

Course evaluator, Johns Hopkins Advanced Agentic AI

Python · LangGraph · LangChain · GPT-4o-mini · ChromaDB · RAG · Human-in-the-loop

NeoPropel — Multi-Tenant Startup Operations Platform Startup SaaS

NeoPropel brings the tools a growing startup usually buys separately into one workspace. It covers projects and tasks, agile planning, testing, ticketing, document management and real-time collaboration, timesheets and approvals, cost analysis, employee onboarding, a product catalog, and manager and leadership dashboards.

I designed and built NeoPropel myself at NeoCap Solutions. It began as a document-management system, which I re-architected into a multi-tenant platform. Each organization is a tenant containing companies, offices, nested departments, and users. Tenant isolation is designed at the row level: a request filter sets the tenant from the authenticated user, and data is scoped by organization. The model also covers subscription tiers with user and storage limits, role-based and partner access, soft delete, and a super-admin role that can manage multiple organizations.

Java · Spring Boot · Spring Security (JWT) · JPA · PostgreSQL · REST APIs
